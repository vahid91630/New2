# ربات اسکلپ طلا (XAUUSD) — حساب ۳۰۰ دلاری

ربات اسکلپ طلا برای MetaTrader 5 به‌همراه موتور بک‌تست و دادهٔ واقعی سال ۲۰۲۶.

## خلاصهٔ صادقانهٔ نتیجه

هدف «روزی ۱۰ دلار با ۳۰۰ دلار» (حدود ۳٫۳٪ در روز) در بک‌تست **به دست نیامد**.

| | اندازهٔ امن (۰٫۰۱ لات) | اندازهٔ پرریسک (ریسک ۲۰٪ در هر معامله) |
|---|---|---|
| میانگین سود روزانه | ‎+۰٫۰۸ دلار | ‎+۴٫۱۹ دلار |
| روزهایی که به ۱۰ دلار رسید | ۳٪ | ۳۲٪ |
| بیشترین افت سرمایه | ۲۶٪ | ۳۶٪ (در دادهٔ دیده‌نشده ۵۵٪) |
| بدترین روز | ‎−۲۳ دلار | ‎−۱۱۶ دلار |
| موجودی پایانی | ۳۱۷ دلار | ۱۲۳۱ دلار |

دوره: ۱ ژانویه تا ۹ نوامبر ۲۰۲۶ (۲۲۲ روز معاملاتی). گزارش کامل در `reports/`.

نکته‌های مهم:

- ۶۷۱ ترکیب از چهار روش (شکست، پولبک روند، شکست محدودهٔ بازگشایی، بازگشت به میانگین) روی ژانویه تا ژوئیه آزمایش شد. فقط ۸۲ تا سودده بودند و از آن‌ها فقط ۲۰٪ روی دادهٔ دیده‌نشدهٔ اوت تا نوامبر سودده ماندند.
- بهترین قاعده (همین که در ربات است) روی دادهٔ دیده‌نشده با ۰٫۰۱ لات ثابت ۵۵ دلار در ۵۳ معامله ساخت. این مقدار از نظر آماری از شانس قابل تشخیص نیست.
- نتیجهٔ ستون پرریسک به مسیر معاملات وابسته است و نباید آن را سود قابل‌انتظار دانست. در آن اندازه هر حد ضرر حدود ۴۶ دلار (۱۵٪ حساب) است.
- برای میانگین ۱۰ دلار در روز حدود ۰٫۰۵ لات لازم است. در آن اندازه، حتی با فرض واقعی بودن برتری بک‌تست، احتمال از دست رفتن نیمی از حساب در ده ماه حدود ۳۵٪ برآورد شد.

این ربات را فقط روی حساب دمو اجرا کنید. این توصیهٔ مالی نیست.

## استراتژی

بازگشت به میانگین در ساعت‌های هم‌پوشانی لندن و نیویورک (۱۲ تا ۲۰ UTC)، کندل ۵ دقیقه:

- خرید: کف کندل زیر باند پایین بولینگر (۲۰، ۲) باشد، RSI(7) کندل قبل زیر ۱۵ باشد و کندل صعودی بسته شود. فروش برعکس (RSI بالای ۸۵).
- حد ضرر ۲٫۵ برابر ATR، حد سود ۰٫۷ برابر حد ضرر.
- خروج زمانی بعد از ۱۲۰ دقیقه و بستن همه‌چیز در ساعت ۲۱ UTC.

قوانین پول: ریسک هدف ۲٪ در هر معامله، توقف روزانه در ‎+۱۰ دلار یا ‎−۵٪، حداکثر ۶ معامله در روز، بدون ورود با اسپرد بالای ۱٫۲ دلار.

## بک‌تست چطور کار می‌کند

- داده: تیک‌های Dukascopy سال ۲۰۲۶ که به کندل ۱ دقیقه با اسپرد واقعی تبدیل شده (`data/XAUUSD_M1_2026.csv.gz`).
- سیگنال در بسته شدن کندل ۵ دقیقه خوانده و در باز شدن دقیقهٔ بعد اجرا می‌شود.
- خرید با قیمت ask و فروش با bid است، به‌علاوهٔ ۰٫۰۵ دلار لغزش.
- اگر حد ضرر و حد سود در یک دقیقه باشند، حد ضرر حساب می‌شود.

```bash
pip install -r requirements.txt
python -m scalper.run_backtest            # اندازهٔ امن
python -m scalper.run_backtest --risk 20  # اندازهٔ پرریسک
```

## ربات سیگنال (برای معاملهٔ دستی)

ربات سفارشی نمی‌فرستد؛ فقط سیگنال می‌دهد (ورود، حد ضرر، حد سود) و خودتان معامله می‌کنید.

فقط ستاپ‌هایی اجازهٔ سیگنال دارند که نرخ بردشان هم در دورهٔ انتخاب قاعده و هم در دادهٔ دیده‌نشده بالای ۵۰٪ باشد:

| ستاپ | سیگنال در هفته | نرخ برد (ژانویه–ژوئیه) | نرخ برد (دیده‌نشده، اوت–نوامبر) | میانگین برد / باخت با ۰٫۰۱ لات | سیگنال می‌دهد |
|---|---|---|---|---|---|
| MR-DAY بازگشت به میانگین | ۵٫۱ | ۵۹٪ (۱۴۹) | ۶۳٪ (۷۶) | ‎+۱۰٫۹ / ‎−۱۳٫۴ دلار | بله |
| ORB-NY شکست بازگشایی نیویورک | ۲٫۷ | ۶۳٪ (۸۱) | ۶۲٪ (۳۷) | ‎+۱۰٫۸ / ‎−۱۳٫۸ دلار | بله |
| TP-LDN پولبک روند | ۲۷٫۵ | ۳۸٪ | ۳۸٪ | ‎+۱۲٫۳ / ‎−۹٫۰ دلار | خیر |
| BO-24 شکست ۲ ساعته | ۲۶٫۰ | ۳۶٪ | ۴۲٪ | ‎+۱۲٫۴ / ‎−۹٫۴ دلار | خیر |

توجه: نرخ برد بالای ۵۰٪ به‌معنی سود نیست. در این ستاپ‌ها هر باخت از هر برد بزرگ‌تر است، پس نقطهٔ سربه‌سر حدود ۵۶٪ برد است و حاشیهٔ سود باریک است.

```bash
python -m scalper.signal_stats        # محاسبهٔ دوبارهٔ نرخ برد ستاپ‌ها
python -m scalper.signals --replay 10 # سیگنال‌های ۱۰ روز آخر داده (بدون MT5)
python -m scalper.signals --test      # پیام آزمایشی به تلگرام
python -m scalper.signals             # زنده، قیمت از MetaTrader 5
```

برای تلگرام، `TELEGRAM_BOT_TOKEN` و `TELEGRAM_CHAT_ID` را به‌صورت متغیر محیطی بگذارید (توکن را در مخزن ننویسید). بدون آن‌ها سیگنال فقط روی صفحه چاپ می‌شود. بخش زنده و ارسال تلگرام اینجا آزمایش نشده است.

## اجرای زنده (MetaTrader 5، ویندوز)

```bash
python -m scalper.live_mt5
```

- تنظیمات در `config/scalper.yaml` است. `dry_run: true` یعنی فقط سفارش را چاپ می‌کند و چیزی نمی‌فرستد.
- `server_utc_offset_hours` را با ساعت سرور بروکر خودتان تنظیم کنید.
- اگر نام نماد در بروکر شما چیز دیگری است (مثل XAUUSDm)، `symbol` را عوض کنید.
- بخش اجرای زنده روی ترمینال واقعی MT5 آزمایش نشده است (اینجا ویندوز و MT5 در دسترس نبود). اول با `dry_run` و بعد روی دمو امتحانش کنید.
